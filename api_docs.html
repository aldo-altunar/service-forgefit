🏋️ ForgeFit API — Endpoints

Base URL: http://localhost:8080 | Total: 23 Endpoints

🏥 Health & Estado
GET /health Público
Comprueba si el servidor está arriba y responde.
GET /health/ready Público
Comprueba la conexión con la base de datos MySQL.
🔐 Autenticación
POST /api/v1/auth/register Público
Registra un nuevo usuario y devuelve el token JWT.
Body: { "name": "Juan Pérez", "email": "juan@example.com", "password": "password123" }
POST /api/v1/auth/login Público
Inicia sesión y genera token JWT.
Body: { "email": "juan@example.com", "password": "password123" }
📊 Dashboard & Perfil
GET /api/v1/dashboard Bearer Token
Resumen completo para la vista principal de la app.
GET /api/v1/users/profile Bearer Token
Obtiene los datos básicos del usuario.
GET /api/v1/users/profile/details Bearer Token
Métricas físicas: peso, altura, edad, km totales, rachas.
PUT /api/v1/users/profile Bearer Token
Actualiza peso, altura y edad.
Body: { "weight_kg": 75.5, "height_cm": 180.0, "age": 25 }
🚶 Actividad Física
GET /api/v1/activity/today Bearer Token
Actividad física registrada para el día actual.
POST /api/v1/activity/steps Bearer Token
Sincroniza pasos, distancia y calorías consumidas.
Body: { "steps": 5000, "distance_km": 3.5, "calories": 200, "active_minutes": 30 }
GET /api/v1/activity/weekly Bearer Token
Historial semanal para gráficas.
🏃 Carreras (Runs)
POST /api/v1/runs/start Bearer Token
Inicia una sesión de running con coordenadas iniciales.
GET /api/v1/runs/active Bearer Token
Obtiene la carrera que está actualmente en progreso.
POST /api/v1/runs/:id/gps Bearer Token
Registra un punto GPS de la ruta.
POST /api/v1/runs/:id/finish Bearer Token
Finaliza la carrera y guarda estadísticas finales.
💪 Rutinas & Nutrición
GET /api/v1/routines/today Bearer Token
Rutina asignada para el día.
GET /api/v1/nutrition/today Bearer Token
Resumen diario de agua, calorías y macros.
POST /api/v1/nutrition/water Bearer Token
Registra vasos o ml de agua consumida.
POST /api/v1/nutrition/meals Bearer Token
Registra una comida (desayuno, almuerzo, merienda, cena).
